# Dark luxury still

Reusable brief for generating photos in this look. @ this file or say **dark luxury still**.

Mood reference: `prompts/dark-luxury-still/reference.png`

Extra subject refs (pick 1–2 that match the request): `prompts/dark-luxury-still/references/`

See `prompts/dark-luxury-still/references/SOURCES.md` for what each file is for.

## Copy-paste prompt

```
Recreate this as a dark-luxury cinematic still, same look as the reference.

SUBJECT: [what to photograph — cars, house, people, objects]
SETTING: [driveway / modern house / street / whatever]
TIME: [dawn / morning / overcast day / golden hour / dusk / blue hour / night / midnight]
ATMOSPHERE: [fog optional — use it when it helps, skip it when the place should stay readable]
ORIENTATION: 9:16 vertical, low camera, slightly looking up

LOCKED LOOK (do not change):
- Mostly charcoal / slate / black, with a light plum cast — not a purple wash
- Honor TIME. Default dusk if TIME is blank
- Still underexposed and quiet — no sunny HDR, no headlights, no streetlights, no warm lamps unless TIME needs the house to stay readable
- Quiet “dark luxury” mood, glossy wet-looking surfaces
- Soft focus, grainy film texture, not sharp HDR
- Fog is optional. When used: cool gray with a hint of violet, never a purple wash or navy cyan
- When no fog: place and cars stay readable
- Minimalist modern architecture if a house is in frame (flat cantilever roof, simple pillar, dark slat fence)
- Large stone pavers underfoot
- No text, no logos invented, no extra props, no people unless I ask

Generate one still. Match the reference mood more than the exact objects.
```

## What to change each time

Fill `SUBJECT`, `SETTING`, `TIME`, and `ATMOSPHERE`.

- `SUBJECT: black G-Wagon + Porsche 911 GT3, rear 3/4 of the Porsche in front`
  `SETTING: stone patio of a minimalist house`
  `TIME: dusk`
  `ATMOSPHERE: light fog`
- `SUBJECT: one black Range Rover, empty passenger door open`
  `SETTING: same house`
  `TIME: night`
  `ATMOSPHERE: no fog`
- `SUBJECT: empty driveway, no cars`
  `SETTING: same house, even darker`
  `TIME: midnight`
  `ATMOSPHERE: no fog`

## Locked look

| Rule | Why it matches the reference |
|---|---|
| Vertical, low angle | Cars feel heavy and close |
| Fog optional | Helps mystery; skip when the house/place should read |
| TIME | dawn / morning / overcast day / golden hour / dusk / blue hour / night / midnight |
| Soft plum underexposure | A hint of violet, not a purple filter |
| Soft grain | Looks like a still, not a render |
| Almost no color | Charcoal dusk, white roof, gray stone only |
